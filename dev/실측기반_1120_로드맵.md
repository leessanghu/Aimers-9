## 2. 실패 패턴

- Trackman 물리량, 구종 기하, 2군 활동: 여러 방법으로 반복 검증했지만 행 단위 실측 이득은 0에 가까움.
- raw categorical ID/CatBoost refit, HGB time-split refit: 로컬은 좋아도 실측에서 일관되게 악화.
- 455개 categorical cross, SHAP masking, feature weight: 새 정보보다 중복·과적합.
- 시드 추가, 용량 확대, mega 6-head: 다양성이 아니라 희석이 되었음.
- 전역 레벨 이동: v48 프로브로 여지가 거의 없음이 확인됨.

## 3. test 분포: 확정과 추정을 분리

### 입력으로 확정된 것

- 평가 행은 season=2025이다.
- 공개 5행은 전부 game_type=R, month=3/6/7이다. 그러나 공식 설명서가 이 5행을 “형식 확인용”으로 명시하므로 이 비율을 전체에 적용하면 안 된다.
- Rule 4 때문에 평가 test 다른 행을 집계해 현재 행 피처를 만드는 것은 불가다.

### 실측에서 추정되는 것

- rookie +0.02 프로브는 v60a 1080.5954→1059.8917, 즉 -20.7037이다.
- 해당 집합 편향을 양수로 보는 합리적 범위에서 rookie 비중은 약 7.4~10.4%다. fold A(2024) rookie 19.86%보다 훨씬 낮다.
- 단일 +probe는 해당 집합의 편향항을 알 수 없어 정확값이 아니다. `submit_probe_rookie_minus.zip`의 실측 1회를 더하면 ±delta 합으로 비중과 편향을 둘 다 정확히 풀 수 있다.
- 2024 fold A보다 실측 BSS가 높은 주요 이유는 실측 집합의 투수-시즌 실력 분산(해상도)이 더 크기 때문이다. 즉 test는 “쉽다”기보다 모델이 잘 구분하는 기존 투수군의 이질성이 크다.

## 4. 새 라벨 taxonomy 감사

reverse/middle/ball/strike를 누적값 차분으로 1,474,300행(99.95%) 복원했다.

| 조건 | 전체 비중 | success rate |
|---|---:|---:|
| not-dangerous & not-ball | 39.02% | 94.05% |
| not-dangerous & ball | 26.53% | 59.10% |
| dangerous & not-ball | 24.03% | 0% |
| dangerous & ball | 10.43% | 0% |

`dangerous = reverse OR middle` 안에서 success는 정확히 0이므로 hurdle 1단은 올바르다. v62는 not-dangerous 65.55% 안의 ball/not-ball을 조건부 head로 분해해 +4.60을 얻었다. 아직 독립 head가 없는 보완 분할은 dangerous 34.45% 안의 ball/not-ball 실패 하위유형이다.

## 5. 이번에 만든 후보

- **v68**: v65(3축 총 0.15)→v66(총 0.24)의 실측 상승방향을 총 0.30(0.10×3)까지 연장. 재학습 없음.
- **v69**: `[y, 1-ball | dangerous]` 2-head 공유트리를 새로 학습하고 v66에 0.08 비중으로 추가. v62의 여집합을 닫는 실패 taxonomy 축.

v65/v66의 실측을 반올림값으로 2차 근사하면 기존 3축 총비중 최적점은 약 0.30~0.32다. 그러나 v66 대비 잔여이득은 약 0~0.5점으로 보여, v68만으로 1120에 갈 수는 없다.

## 6. 1120에 필요한 것

현재 1085에서 1120은 +35점이다. 이를 가중치 튜닝으로 얻는 것은 불가다. 실측으로 확인된 신규 aux 축의 단독 이득이 +2~8점이므로, 상관이 낮은 중간급 축을 최소 5~8개 더 발굴해야 한다.

우선순위:

1. **조건부 실패 taxonomy**: danger-ball(v69), ball 안의 success/failure, strike 안의 failure, reverse/middle 중첩 하위유형을 각각 작은 2-head 모델로 독립 학습. mega head처럼 한 모델에 모두 넣지 않음.
2. **미래 시간해상도 다양화**: future50만 복제하지 말고 future20/100/200을 독립 모델로 학습한 뒤 예측 상관과 실측을 비교. 짧은 폼과 장기 형질의 오차가 달라야 함.
3. **조건부 잔차 target**: count_resid의 성공을 `count×dangerous`, `count×ball`, `platoon×dangerous`에 확장. 피처 cross가 아니라 y에서 해당 조건의 기대값을 뺀 target으로 학습.
4. **독립 실측 후 융합**: 로컬은 새 target 유형에 3/3 반전됐다. 각 축을 v50/v60a 기준 같은 0.08~0.10으로 실측하고, 성공한 축만 예측 상관 기반으로 합친다.
5. **프로브는 모델 개발과 분리**: rookie-minus는 test 이해에 가장 정보량이 높고, month37/lown도 반드시 ±쌍으로만 해석한다. 단일 프로브 점수로 비중을 확정하지 않는다.

현실적 중간 목표는 1090(가중치+신규 1축), 1100(독립 신규 3축), 1110(시간해상도+조건부 잔차 성공), 1120(상관이 낮은 5~8축 융합)으로 두는 것이 맞다.
